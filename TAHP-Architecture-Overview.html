1. System Architecture Overview Core

TAHP follows the industry-standard Agent = Model + Harness paradigm. The system is composed of four core layers, running entirely on local infrastructure with zero server costs.

2. Harness 6-Layer Architecture Framework

The TAHP implements a layered Harness architecture based on the industry-standard six-layer model. Priority layers (P0) are implemented first for maximum ROI.

Implementation Strategy: Start with L1 (Information Boundary) and L6 (Constraint & Recovery) together. These two layers provide the highest ROI with minimal investment. L2 (MCP Tools) follows as P0. L3-L5 are P1 and can be added incrementally.

3. EvoSkill Evolution Cycle Core Engine

The EvoSkill engine drives continuous Skill improvement through a five-stage automated cycle, learning from agent execution failures.
