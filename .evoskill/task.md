# TAHP EvoSkill 任务描述

## 目标
基于约束文件自动发现和进化AI Skills，提升Bug分析准确率和代码适配成功率。

## 诊断引擎目标
- Bug分析准确率: ≥ 85%
- 完整性: 100%必填字段
- 一致性: ≥ 90%
- 单案例: ≤ 5分钟

## 适配引擎目标
- 全自动适配率: ≥ 60%（首次）→ 75%（积累后）
- 编译通过率: 100%
- 回归通过率: ≥ 95%

## 进化策略
1. 加载测试集 → 2. 运行当前Skill → 3. 收集失败 → 4. 分析原因 → 5. 生成改进 → 6. 评估 → 7. 保留最优 → 8. 重复
