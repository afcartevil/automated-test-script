1. 系统架构总览 v3.2 双引擎

TAHP 遵循业界标准的 Agent = Model + Harness 范式，采用双引擎架构：诊断引擎负责 Bug 分析，适配引擎负责版本升级/特性移植/运营商移植。知识库（v3.0 新增）作为双引擎的基础设施，实现知识自动沉淀、文档投喂、约束自动提取和跨模块知识复用。

2. Harness 六层架构 框架

TAHP 实现了基于业界标准六层模型的分层 Harness 架构。优先级层（P0）优先实施，以获得最大投入产出比。

实施策略：从 L1（信息边界）和 L6（约束与恢复）同时启动。这两层以最小投入提供最高回报率。L2（MCP 工具）紧随其后作为 P0。L3-L5 为 P1，可增量添加。

3. EvoSkill 演化周期 核心引擎

EvoSkill 引擎通过五阶段自动化循环驱动持续 Skill 改进，从 Agent 执行失败中学习。

4. 适配引擎 双引擎

适配引擎自动化处理 Android 版本升级（A15→A16→A17...）、特性移植和运营商需求移植。通过 API 迁移规则库实现跨版本经验复用，知识库（v3.0）为规则库提供自动更新和经验沉淀能力，自动化率从 40% 逐步提升至 75%+。

跨版本复用：API 迁移规则库是核心资产。A15→A16 积累的迁移规则可直接复用于 A16→A17，自动化适配率从首次约 40% 逐步提升至 75%+。
