## ⚠️ 需要关注的事项

### 技术依赖
- Python 3.10+ 环境（用于向量搜索和文档导入）
- torch/torch-cpu 依赖（可能较大，推荐用 torch-cpu）
- 多个第三方库的兼容性

### 性能考虑
- 知识库 > 1000 条时需考虑索引优化
- 向量模型首次加载较慢（缓存后快速）
- 大文件导入需异步处理

### 维护成本
- 向量模型定期更新
- ChromaDB 数据库备份
- 知识条目质量审核
- 性能监控
