# 最小用例目录（非 py）

本目录用于演示框架用法，所有示例均为文档文件，不会被 pytest 自动收集。

## 文件说明

- `case-run-cli.md`：最小运行命令示例
- `case-marker-minimal.md`：所有自定义 marker 的最小示例
- `case-adb-methods.md`：所有 ADB API 的最小调用示例
- `case-framework-features.md`：框架特性最小示例（fixture、报告、过滤链路）

## 使用建议

- 复制示例代码时，请粘贴到真实测试文件（`test_*.py`）再执行。
- 新增框架能力时，请同步补充对应最小用例文档。
