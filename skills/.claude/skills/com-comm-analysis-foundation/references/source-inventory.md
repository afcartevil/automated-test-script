## 3. 明确排除范围
当前阶段不纳入 Skill 语料处理：
- `mp4`
- `db`
- 临时锁文件（如 `~$*.pptx` / `~$*.docx`）

## 4. 后续抽取原则
1. 先抽取海外 8 个 PDF，形成标准基线。
2. 再按主题域从雏鹰资料中补强，不做全量无差别读取。
3. 仅保留对售后问题分析有直接帮助的内容：
   - 问题分类
   - 抓 log 要求
   - 流程节点
   - 关键日志与判断依据
   - 常见根因
   - 升级路径
4. 对偏背景介绍、管理类、通用入职类内容，只在必要时摘取少量上下文，不纳入核心知识。
