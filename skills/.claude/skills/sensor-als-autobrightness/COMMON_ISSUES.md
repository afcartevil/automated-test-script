## 详细说明

### 问题1：从暗环境到亮环境下，屏幕不会变亮

**日志特征**：
```text
对比底层lux值与屏幕背光值，lux与背光值可以对应起来，但是lux较小，在亮环境下lux值应该较大。
```

**根因分析**：结论是用户没有对光感进行校准。

**排查建议**：
- 先确认 `*#801#` 工模中的sensor是否已完成校准。
- 再结合 `lux` 与 `brightness_val` 的对应关系排除链路问题。

### 问题2：光感校准的情况下，全黑环境光感值lux不等于0

**日志特征**：
```text
在全黑环境下，日志中的 lux 或 g_data 仍持续为非0值。
```

**根因分析**：光感驱动计算lux算法问题，需增加lux在很小时置0的逻辑。

**排查建议**：
- 核对原始ALS值、算法估算值和最终lux值的换算过程。
- 重点检查低亮度场景下的置零门限逻辑。

### 问题3：从室内走到室外，亮度升得慢

**日志特征**：
```text
环境变化后，lux值变化和背光变化都存在，但光感上报和背光跟随节奏偏慢。
```

**根因分析**：底层光感数据上报的太慢。

**排查建议**：
- 统计连续多笔lux上报间隔。
- 对比 `g_data` 变化开始时刻与 `brightness_val` 开始变化时刻。
