# MODEM 大版本升级主控工作流

## 工作流概述
本工作流定义了 MODEM 大版本升级 P1 阶段的完整执行流程，由主控技能协调三个子技能完成升级任务：RF 参数移植、宏控移植、锁卡 NV 修改。

## 执行步骤

### 阶段 1：初始化与参数收集
1. **开场白**：向用户介绍本技能的功能和预期效果
2. **收集 4 个全局路径参数**（保存在全局记忆中）：
   - 询问用户 **Path_A_Pub**：代码 A（原分支）的公共仓路径
   - 询问用户 **Path_A_Priv**：代码 A（原分支）的私有仓路径
   - 询问用户 **Path_B_Pub**：代码 B（目标分支）的公共仓路径
   - 询问用户 **Path_B_Priv**：代码 B（目标分支）的私有仓路径
3. **收集 BOM 名称**：
   - 询问用户 **BOM_Name**：项目 BOM 名称，用于定位项目文件夹
   - 示例：ae10_h833_a1, cm7_h781, x6870_h781_f1, lk7k_h582
4. **收集变更后 BOM 名称**：
   - 询问用户 **BOM_Name_Target**：变更后的 BOM 名称，用于命名目标分支项目文件夹
   - 示例：x6856_h971_a1
5. **收集 RF 参数目标位置**：
   - 询问用户 **RF_TARGET_LOCATION**：RF 参数要移植到哪个仓
   - 选项：public / private
6. **验证路径有效性**：检查所有路径是否存在且可访问

### 阶段 2：RF 参数移植
1. **调用 RF 参数移植子技能**：
   - 传入参数：
     - Path_A_Priv（原分支私有仓）
     - Path_A_Pub（原分支公共仓）
     - Path_B_Priv（目标分支私有仓）
     - Path_B_Pub（目标分支公共仓）
     - BOM_Name（项目 BOM 名称）
     - BOM_Name_Target（变更后的 BOM 名称）
     - RF_TARGET_LOCATION（RF 参数目标位置）
   - 等待子技能执行完成
2. **接收返回结果**：
   - 获取上下文变量 X（RF 参数版本号）
   - 获取上下文变量 Y（RF 参数配置标识）
   - 获取移植详情（来源位置、目标位置、文件数量）
3. **确认执行结果**：向用户展示移植结果，确认无误后继续

### 阶段 3：宏控移植（公共仓和私有仓）
1. **调用宏控子技能**：
   - 传入参数：
     - Path_A_Pub（原分支公共仓）
     - Path_A_Priv（原分支私有仓）
     - Path_B_Pub（目标分支公共仓）
     - Path_B_Priv（目标分支私有仓）
     - X（RF 参数版本号）
     - Y（RF 参数配置标识）
     - BOM_Name（原 BOM 名称）
     - BOM_Name_Target（变更后的 BOM 名称）
   - 等待子技能执行完成
2. **接收返回结果**：获取宏控代码修改统计信息（区分公共仓和私有仓）

### 阶段 4：锁卡 NV 修改（可选）
1. **询问用户是否需要修改锁卡 NV**：
   - 提问："是否需要修改锁卡 NV？(是/否)"
   - 如果用户回答"否"，跳过此阶段，直接进入结果汇总阶段
   - 如果用户回答"是"，继续执行锁卡 NV 修改子技能
2. **调用锁卡 NV 修改子技能**：
   - 传入参数：
     - Path_B_Pub（目标分支公共仓）
     - BOM_Name_Target（变更后的 BOM 名称）
   - 等待子技能执行完成
3. **接收返回结果**：获取锁卡 NV 修改统计信息

### 阶段 5：结果汇总与输出
1. **整理执行报告**：
   - RF 参数移植结果（来源→目标、文件数量）
   - 宏控代码修改结果（公共仓和私有仓）
   - 锁卡 NV 修改结果（如已执行）
   - 上下文变量值
2. **输出总结**：向用户展示完整的升级报告
3. **结束对话**：询问用户是否需要其他帮助

## 异常处理流程
1. **路径无效**：提示用户检查路径并重新输入
2. **BOM 名称未找到**：提示用户检查 BOM 名称，或手动指定项目路径
3. **子技能执行失败**：展示错误信息，询问用户是否重试
4. **用户中断**：保存当前进度，允许用户稍后继续

## 上下文变量传递
| 变量名 | 来源 | 用途 |
|--------|------|------|
| Path_A_Pub | 用户输入 | 原分支公共仓路径，传递给 RF 子技能、宏控子技能、锁卡 NV 子技能 |
| Path_A_Priv | 用户输入 | 原分支私有仓路径，传递给 RF 子技能和宏控子技能 |
| Path_B_Pub | 用户输入 | 目标分支公共仓路径，传递给 RF 子技能、宏控子技能、锁卡 NV 子技能 |
| Path_B_Priv | 用户输入 | 目标分支私有仓路径，传递给 RF 子技能和宏控子技能 |
| BOM_Name | 用户输入 | 项目 BOM 名称，传递给 RF 子技能和宏控子技能 |
| BOM_Name_Target | 用户输入 | 变更后的 BOM 名称，传递给 RF 子技能、宏控子技能、锁卡 NV 子技能 |
| RF_TARGET_LOCATION | 用户输入 | RF 参数目标位置，决定 RF 移植到 Pub 还是 Priv |
| X | RF 参数移植子技能 | RF 参数版本号，传递给宏控子技能 |
| Y | RF 参数移植子技能 | RF 参数配置标识，传递给宏控子技能 |

## 技能调用协议
### 调用 RF 参数移植子技能
```json
{
  "skill_name": "rf_param_skill",
  "action": "execute",
  "parameters": {
    "Path_A_Priv": "...",
    "Path_A_Pub": "...",
    "Path_B_Priv": "...",
    "Path_B_Pub": "...",
    "BOM_Name": "...",
    "BOM_Name_Target": "...",
    "RF_TARGET_LOCATION": "..."
  }
}
```

### 调用宏控子技能
```json
{
  "skill_name": "macro_control_skill",
  "action": "execute",
  "parameters": {
    "Path_A_Pub": "...",
    "Path_A_Priv": "...",
    "Path_B_Pub": "...",
    "Path_B_Priv": "...",
    "X": "...",
    "Y": "...",
    "BOM_Name": "...",
    "BOM_Name_Target": "..."
  }
}
```

### 调用锁卡 NV 修改子技能
```json
{
  "skill_name": "lock_nv_skill",
  "action": "execute",
  "parameters": {
    "Path_B_Pub": "...",
    "BOM_Name_Target": "..."
  }
}
```
