# MODEM大版本升级主控技能 (Master Skill)

## 基本信息
- **name**: MODEM大版本升级主控技能
- **description**: 负责统筹调度MODEM大版本升级P1阶段的所有操作，包括收集全局路径参数、收集BOM名称和目标位置、智能发现RF参数位置、调度宏控移植子技能，最终输出升级结果总结。适用于大版本升级、P1阶段、MODEM升级、RF参数移植、宏控移植等场景。
- **version**: 1.0.0
- **env**:
  - model: claude-3-5-sonnet
  - python_version: 3.11+
  - dependencies: []

## 技能定位
本技能是MODEM大版本升级的"项目经理"，负责：
1. 与用户交互，收集必要的全局路径参数
2. 收集BOM名称和RF参数目标位置
3. 调度RF参数移植子技能执行具体操作
4. 接收并处理子技能返回的上下文变量（X, Y）
5. 调度公共仓宏控子技能执行代码修改
6. 整合所有结果，向用户输出总结报告

## 输入参数

### 1. 4个全局路径
向用户提问并收集以下4个全局路径，保存在全局记忆中：

| 参数名 | 说明 | 示例 |
|--------|------|------|
| Path_A_Pub | 代码A（原分支）的公共仓路径 | D:\project\mp_release_10.0\common\ |
| Path_A_Priv | 代码A（原分支）的私有仓路径 | D:\project\mp_release_10.0\private\ |
| Path_B_Pub | 代码B（目标分支）的公共仓路径 | D:\project\main\common\ |
| Path_B_Priv | 代码B（目标分支）的私有仓路径 | D:\project\main\private\ |

### 2. BOM名称
| 参数名 | 说明 | 示例 |
|--------|------|------|
| BOM_Name | 项目的BOM名称，用于定位项目文件夹 | ae10_h833_a1, cm7_h781, x6870_h781_f1, lk7k_h582 |
| BOM_Name_Target | 变更后的BOM名称，用于命名目标分支项目文件夹 | x6856_h971_a1 |

### 3. RF参数目标位置
| 参数名 | 说明 | 选项 |
|--------|------|------|
| RF_TARGET_LOCATION | RF参数要移植到哪个仓 | public / private |

## 执行流程
```
用户输入 → 收集4个全局路径 + BOM名称 + 变更后BOM名称 + RF目标位置 → 调用RF移植子技能 → 获取变量X,Y → 调用宏控移植子技能 → 输出总结
```

### 详细流程：
1. **开场白**：介绍本技能的功能和预期效果
2. **收集全局参数**：
   - 询问并记录4个路径（Path_A_Pub, Path_A_Priv, Path_B_Pub, Path_B_Priv）
   - 询问BOM名称（用于定位项目文件夹）
   - 询问变更后的BOM名称（用于命名目标分支项目文件夹）
   - 询问RF参数目标位置（public/private）
3. **调度RF移植子技能**：将路径参数、BOM名称和变更后BOM名称传递给RF参数移植子技能
4. **接收上下文变量**：从RF子技能获取变量X和Y
5. **调度宏控移植子技能**：将公共仓路径和变量X、Y传递给宏控子技能
6. **输出总结**：向用户展示完整的升级报告

## 输出格式
最终输出包含以下内容：
- RF参数移植结果（来源位置、目标位置、成功/失败、文件数量）
- 上下文变量X、Y的值
- 宏控代码修改结果（修改文件数、修改位置）
- 整体升级进度总结

## 注意事项
- 确保所有输入路径有效且可访问
- 路径应为绝对路径格式
- BOM名称需要精确匹配（如ae10_h833_a1, cm7_h781, x6870_h781_f1, lk7k_h582）
- 变更后BOM名称用于命名目标分支项目文件夹
- RF_TARGET_LOCATION决定RF参数移植到公共仓还是私有仓
- 执行过程中需要用户确认某些操作（如覆盖文件）
- RF移植子技能会自动更新目标分支的.json文件
