# 典型案例

《展锐平台内核死机问题分析SOP》**V1.0（2026-05-12）** 正文中**未包含独立「典型案例」章节**（无案例1/案例2 等结构化案例）。

使用本 Skill 时：

- 可将实际工单中的 **现象 + 关键日志摘录 + 映射结果** 补充为团队内案例库；
- 分析分支与处置要点可先参考 [COMMON_ISSUES.md](COMMON_ISSUES.md) 中的 **KE-Oops/Panic** 与 **watchdog_timeout（含 cm4）** 分支说明。

若后续 SOP 修订增加案例章节，应在本文件中按「现象 / 分析过程 / 根因 / 关键日志」结构补充，并保持与 SOP 原文一致。
