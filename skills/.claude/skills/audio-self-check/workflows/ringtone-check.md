# 铃声资源配置检查

铃声配置参考文档：<https://transsioner.feishu.cn/docx/AjcWd66AVoq192xUNHvcj5jVn0b>

## 必需输入

- `铃声检查类型`
- `升级后铃声资源路径`

可选补充：

- `代码基础路径`
- `项目名`

## 触发与路由

检查规则：以下操作仅对比文件是否存在差异，不得修改“参考文档”和提供的文件中的内容。

需要用户在 `铃声检查：` 后输入铃声检查类型，并按以下规则匹配（命中即执行对应分支，其他跳过；**(5)(6)(7) 须同时提供 `项目名`，且优先于同类型的 (1)(3)**）：

- 用户输入 `TECNO铃声检查`，则执行 TECNO，其他跳过。
- 用户输入 `Infinix铃声检查`，则执行 Infinix，其他跳过。
- 用户输入 `TECNO阿尔及利亚铃声检查`，则执行 TECNO DZ，其他跳过。
- 用户输入 `Infinix阿尔及利亚铃声检查`，则执行 Infinix DZ，其他跳过。
- 用户输入 `TECNO铃声检查`，且 `项目名` 为 `cm5_h8918`、`cm6_h8918`、`cm7_h781`、`cm8_h973` 之一，则执行 TECNO CM 系列。
- 用户输入 `TECNO阿尔及利亚铃声检查`，且 `项目名` 为 `cm5_h8918`、`cm6_h8918`、`cm7_h781`、`cm8_h973` 之一，则执行 TECNO CM 系列 DZ。
- 用户输入 `TECNO铃声检查`，且 `项目名` 包含 `lj6`、`lj7`、`lj8`、`lj9` 之一，则执行 POVA7。

## 目录扫描基线（必须）

为确保能正常获取 `升级后铃声资源路径` 下文件，扫描必须按以下回退链执行：

1. 目录存在性校验：逐个确认 `ringtones`、`notifications`、`alarms` 子目录存在。
2. 对每个子目录按顺序扫描（命中即停止回退）：
   - 方案A：`target_directory=<升级后铃声资源路径>/<子目录>`，`glob_pattern=**/*.*`
   - 方案B：`target_directory=<升级后铃声资源路径>`，`glob_pattern=<子目录>/**/*.*`
   - 方案C：`target_directory=<升级后铃声资源路径>/<子目录>`，`glob_pattern=**/*`
   - 方案D（Glob 假阴性回退）：当 A/B/C 均为 0 文件时，用本机终端列目录。Windows PowerShell 示例（`<子目录>` 为 `ringtones` / `notifications` / `alarms` 之一）：

```powershell
Get-ChildItem -LiteralPath (Join-Path '<升级后铃声资源路径>' '<子目录>') -File -Force |
  Select-Object -ExpandProperty Name
```

   - 非 Windows 环境可用 `ls -1` 等等价方式列出文件名。
3. 仅当 A/B/C/D 均无结果（或 D 因权限等原因失败且已在结论中说明），才判定该目录为空目录。
4. 文件名归一化后再比对：统一去掉扩展名（至少 `.ogg`、`.mp3`）。

## HiOS 平台版比对前提（TECNO / TECNO DZ）

对比「HiOS平台版音效集成核对表」下 **铃声 / 通知音 / 闹铃** 任一列表前，必须先应用本规则：

1. 读取参考文档中该列表每一行的 **「备注」** 列（若表格为纯文本列表，则同时查阅文档 **「变更（更新）记录」** 中与该列表相关的 OS15 删除说明）。
2. 若某行的「备注」中存在 **「此文件在OS15中删除」** 或语义等价的字样（如「OS15中删除」「删除HIOS15通知音：xxx」「删掉 HiOS15 … 中的 xxx.ogg」），则 **将该行对应音效从本次比对基准中剔除**，不与 `升级后铃声资源路径` 下本地文件做存在性对比。
3. 剔除项须在结论中 **逐条列出**（类别 + 标题/文件名），并说明跳过原因，避免误判为缺失。
4. 仅对剔除后的参考列表与本地目录做 diff；本地 **不应** 因未包含已删除项而记为「缺失」。

## TECNO 铃声检查
