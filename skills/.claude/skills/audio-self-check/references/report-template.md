# 音频自检结论模板（必须中文）

```markdown
# 音频自检结论

## 执行范围
- 本次执行章节：<列出执行到的章节>
- 跳过章节及原因：<如无则写“无”>

## 检查结果
- 音频软件配置：<通过/存在差异/未执行 + 说明>
- DTS音效自检：<通过/存在差异/未执行 + 说明>
- 杜比音效自检：<通过/存在差异/未执行 + 说明>
- 铃声资源配置确认：<通过/存在差异/未执行 + 说明>
- PA参数路径检查：<通过/已按规则修改/未执行 + 说明>

## 差异与改动清单
- 差异项：<逐条列出；无则写“无”>
- 改动项：<逐条列出文件与修改点；无则写“无”>

## 风险与待确认
- <需要用户确认的事项；无则写“无”>

## 总结结论
- <一句中文结论>
```

使用要求：

- 所有结论必须使用中文。
- 若章节未执行，必须说明未执行原因。
- 若属于“仅对比”章节，改动项必须为“无”。
