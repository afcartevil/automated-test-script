# 通信框架 Agent 自动适配测试 Skill

## 使用场景
- TAHP 控制台「AI 适配调试 > 通信框架」点击「Agent 自动适配」时触发。
- 目标：验证 Agent 能按步骤创建文件并多次写入，让前端可展示任务规划、工具使用、文件修改路径。

## 输入参数
- `prj_path`（必填）：项目路径（绝对路径）
- `user_notes`（可选）：补充说明

## 执行步骤（必须按顺序）
1. 校验 `prj_path` 是否存在；若不存在，明确报错并停止。
2. 在 `prj_path` 下创建目录 `agent-test-output`（若已存在可复用）。
3. 创建文件：`agent-test-output/comm_framework_agent_test.txt`，先写入第一段：
   - 标题
   - 步骤 1 说明
4. 第二次写入（追加）：写入当前时间（ISO 时间）与「步骤 2 完成」。
5. 第三次写入（追加）：写入地点（可用用户输入或默认“深圳”）与「步骤 3 完成」。
6. 第四次写入（追加）：写入天气（可用用户输入或默认“晴”）与「步骤 4 完成」。
7. 最后输出：
   - 最终文件绝对路径
   - 文件总行数
   - 每一步是否成功

## 输出格式
必须包含以下小节：
- `## 任务规划回顾`
- `## 文件修改清单`
- `## 执行结果`

## 注意事项
- 所有路径必须使用用户输入的 `prj_path`，不得改写到其他目录。
- 文件写入必须至少 4 次（可通过 Write/Edit/ApplyPatch 等工具实现）。
- 如果写入失败，必须说明失败步骤与原因。
