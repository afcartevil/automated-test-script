# 报告模板

执行该 Skill 后，最终回复使用以下结构。

```markdown
## 输入摘要

- 升级后 vnd/vendor 路径：`<base_code_sunmao>`
- 项目编译选项：`<project_name>`
- 项目目录：`<project_name1>_<project_name2>`
- 特性：`<features>`

## 自检结果

- `<feature>`:
  - 结论：`<已适配/未适配/无法判断>`
  - 检查文件：`<文件路径>`
  - 检查项：`<宏控或文件项>`
  - 证据：`<命中行/实际值/缺失说明>`
  - 阻塞项：`<问题或无>`

## 汇总

- 已适配：`<数量和特性>`
- 未适配：`<数量和特性>`
- 无法判断：`<数量和特性>`

## 开发者待确认

- `<需要开发者补充或复核的内容；没有则写 无>`
```

如果因为不确定项停止执行，将未回答的问题放在 `阻塞项` 或 `开发者待确认` 下，不要声称该特性已完成。
