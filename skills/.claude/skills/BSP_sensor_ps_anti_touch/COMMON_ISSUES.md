# 常见问题与原因对照表

| 序号 | 问题现象 | 日志特征 | 根因说明 |
|------|----------|----------|----------|
| 1 | 遮挡距感，没有正常触发防误触界面 | 监听窗口内没有 `pdb:pre and now state is 0 1` 或 `anti pre and now state is 0 1`；或底层有 `0 1`，但上层没有收到 `onSensorChanged distance:1.0` | 可能是距感没有校准、测试手法未遮住距感、距感硬件异常，或链路传输异常 |
| 2 | 取消遮挡距感，没有退出防误触界面 | 底层没有正常上报 `1 0`，或上层没有响应退出状态 | 可能是距感状态切换异常，或上层口袋防误触退出逻辑异常 |
| 3 | 没有遮挡距感，自动进入防误触界面 | 监听窗口内出现 `0 1`，且问题现象为不应触发却触发 | 多数是距感未校准、机器结构位移遮挡距感、底噪偏大导致误识别靠近 |

## 详细说明

### 问题1：遮挡距感，没有正常触发防误触界面

**日志特征**：
```text
1. main_log中存在上层监听日志：
   Sensor name="pdb"
   或
   Sensor name="anti_touch"

2. scp_log中未出现对应窗口内的 0 1 进入口袋模式打印；
   或者
   出现了 0 1，但main_log没有对应 onSensorChanged distance:1.0。
```

**根因分析**：可能是距感没有校准、测试时没有真正遮挡距感、距感硬件问题，或者底层到上层的信息传输链路异常。

**排查建议**：
- 优先确认距感是否已校准。
- 复核测试手法是否真正遮挡到对应距感区域。
- 若底层有 `0 1` 而上层无接收，优先排查链路传输。

### 问题2：取消遮挡距感，没有退出防误触界面

**日志特征**：
```text
1. 进入口袋模式后，scp_log中未出现对应的 1 0 退出状态；
2. 或scp_log已出现 1 0，但main_log中没有对应的退出表现。
```

**根因分析**：可能是距感状态切换异常，也可能是上层口袋防误触退出逻辑未正确处理退出状态。

**排查建议**：
- 检查底层是否有连续完整的 `0 1 -> 1 0` 状态链路。
- 如果底层完整而上层未退出，转上层口袋防误触模块分析。

### 问题3：没有遮挡距感，自动进入防误触界面

**日志特征**：
```text
监听窗口内出现 pdb:pre and now state is 0 1
或 anti pre and now state is 0 1
且main_log中收到 onSensorChanged distance:1.0，并显示 SHOW_INADVERTENTVIEW, VISIBLE。
```

**根因分析**：这类问题多由距感未校准、机器结构位移遮挡距感、距感底噪偏大导致误识别为靠近状态。

**排查建议**：
- 先确认距感校准状态。
- 再检查结构件是否遮挡距感。
- 结合多次窗口分析，确认是否为持续性误触发而非偶发测试误差。
